# 1. 睡眠与休息

- 床垫 + 四件套（2套）： 甚至可以不需要床架，高质量的床垫保证睡眠即可。

- 四季被（1条）： 选择厚度适中的羽绒被或控温被，根据季节调整睡衣厚度。

- 适合夏天盖的毯子。


# 2. 个人穿戴

- 基础款上衣（5-7件）： 纯色T恤、衬衫或卫衣，颜色以黑白灰为主，方便任意搭配。

- 裤装（10条）： 牛仔裤8条，休闲裤、运动短裤各一。

- 外套（2-3件）： 应对不同季节（如一件夹克、一件羽绒服）。

- 鞋类（4双）： 运动鞋2双（日常/运动）、正装皮鞋/休闲鞋（工作/正式场合）、拖鞋。

- 内衣裤 + 袜子： 满足一周换洗的量。

# 3. 洗漱与个护

- 洗护： 洗发水，一块高品质香皂搞定全身。

- 洁面 + 保湿乳： 最基础的皮肤护理。

- 牙刷 + 牙膏 + 毛巾（1条）。

- 剃须刀 / 理发器： 保持面部整洁。

# 4. 烹饪与饮食

- 电饭煲。

- 电磁炉。

- 餐具（1套）： 碗、盘子、筷子、勺子。

- 水杯： 保温杯或马克杯。

# 5. 数字化与工作

- 手机。

- 电脑。配高档电脑桌和座椅。

# 6. 清洁与收纳

- 无线吸尘器或拖把： 保持地面干净。

- 多功能清洁剂（如酒精喷雾）： 搞定厨房、卫生间和桌面。

- 功能背包（1个）： 满足日常通勤和短期出行。
